# Sales and Customer Insights Dashboard

## 📖 Overview
This project focuses on analyzing a **Pizza Sales dataset** using **Microsoft SQL Server**.  
It provides valuable business insights such as **total revenue**, **average order value**, **top-selling pizzas**, and **sales trends** across different time periods, pizza sizes, and categories.

The analysis helps the pizza store understand:
- Which pizzas are generating the most revenue  
- Which sizes and categories are most popular  
- How customer demand varies by day and month  

---

## 🧠 Key Objectives
- Calculate essential **sales KPIs**
- Identify **top and bottom-performing pizzas**
- Analyze **daily and monthly sales trends**
- Understand **customer buying patterns** by category and size

---

## ⚙️ Technologies Used
- **SQL Server** (T-SQL)
- **Microsoft SQL Server Management Studio (SSMS)**
- **pizza_sales** database

---

## 🧩 Dataset Details

**Table Name:** `pizza_sales`  

| Column Name       | Description                        |
|------------------|------------------------------------|
| `pizza_id`       | Unique identifier for each pizza   |
| `order_id`       | Unique order number                |
| `pizza_name_id`  | Pizza name code                    |
| `quantity`       | Number of pizzas sold              |
| `order_date`     | Date of the order                  |
| `order_time`     | Time of the order                  |
| `unit_price`     | Price per pizza                     |
| `total_price`    | Total price for the order           |
| `pizza_size`     | Size of the pizza (S, M, L, XL)    |
| `pizza_category` | Category (Veg, Non-Veg, Special)   |
| `pizza_ingredients` | Ingredients list                  |
| `pizza_name`     | Name of the pizza                   |
